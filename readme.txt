A responsive WordPress blog theme by Anders Norén and Sergey Boychenko, based on Rams.

== Installation ==

Upload and activate the theme under Appearance → Themes. Set the accent color under Appearance → Customize.

== Post formats ==

- Gallery: Select the Gallery format and upload images to the post.
- Quote: Select the Quote format and put the quote in a blockquote. Add a More block after the quote to keep the rest of the post out of the archive preview.
